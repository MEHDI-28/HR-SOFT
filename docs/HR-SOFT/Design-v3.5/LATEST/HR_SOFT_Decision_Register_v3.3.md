## 2. قابلیت‌های مشاهده‌شده در Admino (نه الزاماً تأیید نهایی HR-SOFT)

- فرم country/city
- لایه سازمانی، واحد سازمانی، موقعیت سازمانی، پایه سازمانی، وظایف، وضعیت سمت، امور/دفتر، امتیاز
- چارت اجرایی و انتقال زیرمجموعه
- گروه کاربران، کاربر، IP permissions، force password change، similar access
- تابلو اعلانات
- گزارش‌های پرسنلی
- بخش‌های پرسنلی، گردش کار، حضور و غیاب، پورتال، رستوران و سایر سرویس‌ها

جزئیات کامل هر صفحه و behaviorهای تأییدنشده نباید فرض شوند.

## 3. پیشنهادهای فنی (نیازمند review پیش از اجرا)

- Modular Monolith
- Supabase/PostgreSQL/Auth/Private Storage
- permission resolver مرکزی
- wrapper API و عدم دسترسی مستقیم کلاینت به جداول داخلی
- file owner registry
- company-safe composite foreign keys
- transactional outbox
- bitemporal history
- CIDR-based IP policy
- AD identity broker
- default group per user/system
- read models برای گزارش‌ها

## 5. قواعد حاکم بر ابهام
- ابهام با حدس به تصمیم قطعی تبدیل نمی‌شود.
- برای ادامه طراحی، گزینه محافظه‌کارانه ثبت می‌شود.
- هر پیشنهاد در سند با برچسب proposal باقی می‌ماند تا منبع/تصمیم تکمیل شود.
- هیچ migration روی production بدون preflight، backup، tests و مجوز اجرا نمی‌شود.
